# МИМ Дафтар — Дастур / Инструкция

## Тоҷикӣ

**Кушодан:** нишонаи «МИМ Дафтар»-ро дар телефон пахш кунед. Бори аввал почта ва паролро нависед.

**Ҳар рӯз — тугмаҳои калон дар саҳифаи асосӣ:**

| Тугма | Кай пахш кардан |
|---|---|
| **Фурӯхтем** | Салфетка фурӯхтед. Мизоҷро интихоб кунед, чанд баста, ва пул гирифтед ё ба қарз. |
| **Салфетка сохтем** | Дар сех баста сохтед. Чанд баста ва аз кадом рулон. |
| **Пул гирифтам** | Мизоҷ қарзашро дод. |
| **Харҷ кардам** | Музд, барқ, халта, нақлиёт ва ғайра. |
| **Рулон харидам** | Ҷамбо-рулон харидед. Вазни ҳар рулон ва чанд пул додед. Рақами рулонро бо маркер рӯи рулон нависед. |
| **Рулон тамом шуд** | Рулон дар дастгоҳ тамом шуд. Барнома ҳисоб мекунад, ки аз он чанд баста шуд. |
| **Мизоҷон** | Рӯйхати тарабхонаҳо, телефон, нарх. |
| **Ҳисобкунак** | «Агар…» — нархи рулон ё андозаи дигар — фоида чанд мешавад. |

**Бе интернет:** барнома кор мекунад. Ҳама сабтҳо дар телефон мемонанд ва вақте интернет пайдо шавад, худашон фиристода мешаванд. Дар боло «Офлайн» менависад — ин хуб аст.

**Хато кардед?** Сабтро пахш кунед → «Ҳазф кардан» → боз як бор пахш кунед. Баъд дуруст нависед.

**Ҳар моҳ:** «Ҳисобот» → «Нусхаи эҳтиётӣ» — файлро ба писаратон диҳед.

## Русский

**Открыть:** нажмите значок «МИМ Дафтар» на телефоне. В первый раз введите почту и пароль.

**Каждый день — большие кнопки на главной:**

| Кнопка | Когда нажимать |
|---|---|
| **Продали** | Продали салфетки. Выберите клиента, сколько пачек, получили деньги или в долг. |
| **Сделали салфетки** | Сделали пачки в цеху. Сколько пачек и с какого рулона. |
| **Получил деньги** | Клиент отдал долг. |
| **Потратил** | Зарплата, свет, пакеты, транспорт и т.д. |
| **Купил рулоны** | Купили джамбо-рулоны. Вес каждого и сколько заплатили. Напишите номер маркером на рулоне. |
| **Рулон закончился** | Рулон на станке закончился. Программа посчитает, сколько пачек с него вышло. |
| **Клиенты** | Список ресторанов, телефоны, цены. |
| **Калькулятор** | «А если…» — другая цена рулона или размер — какая будет прибыль. |

**Без интернета:** приложение работает. Все записи остаются в телефоне и отправятся сами, когда появится интернет. Сверху написано «Офлайн» — это нормально.

**Ошиблись?** Нажмите на запись → «Удалить» → нажмите ещё раз. Потом запишите правильно.

**Раз в месяц:** «Отчёт» → «Резервная копия» — отдайте файл сыну.
